Short data analyses on Kosova's economy, written for a general audience. Each
piece lives in its own folder with its own README, its code, its data and its
figure.

## Method

The same standards apply to every piece here:

- **Official statistics and open data only** — ASK, Eurostat, the World Bank,
  and public open-data sources. No proprietary or paywalled inputs.
- **Reproducible R.** Every number and figure can be regenerated by running the
  scripts in the piece's folder. Raw pulls are saved before parsing.
- **Stated limitations.** Each README ends with what the data cannot support,
  including where official figures are estimates or affected by non-response.
- **One clear finding per piece.** If an analysis suggests two, it is split.
- **Descriptive, not causal.** These are associations and comparisons. Language
  is kept to "consistent with" and "coincides with" unless a design exists that
  would justify more, and none here claims one.
